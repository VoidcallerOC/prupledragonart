# Purple Dragon Artwork — homepage concept

Concept preview for Forge-CT's client Purple Dragon Artwork ([@purpledragonartwork](https://www.instagram.com/purpledragonartwork/)). **Not published or deployed.**

## Preview

Open `index.html` in a browser. It's one self-contained file; only the Google Fonts load from the network.

## Before this goes live

- **Photos:** every `<figure class="ph">` is a labeled placeholder (search the file for `REPLACE`). Swap each one for the artist's own photo, with real `alt` text.
- **Not on the page by design:** prices, shipping, turnaround times, reviews, contact details other than Instagram, and pop-up hours. Add these only after the artist confirms them.
- **Digital art** sits in a separate note until its products and ordering details are confirmed.
- **Pop-up hours** point to Instagram, because the bio and recent captions list different schedules.
